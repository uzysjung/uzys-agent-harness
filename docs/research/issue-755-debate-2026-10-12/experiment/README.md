# #755 채택 실험 — 현재 앵커(A) vs 최종 문안(B) (2026-10-12)

## 방법
- 실행: `claude -p --setting-sources project --permission-mode acceptEdits --disallowedTools Bash WebFetch WebSearch`, 모델 claude-opus-5-5. 과업마다 임시 프로젝트(설치 전 상태)를 만들고 `CLAUDE.md` 만 A/B 로 바꿨다.
- 격리 대조: 같은 질문을 `--setting-sources project` 로 돌리면 사용자 전역 CLAUDE.md 의 절을 못 보고(NO), 제한 없이 돌리면 본다(YES) — 실험이 이 리포·사용자 지시에 오염되지 않았다.
- 과업(`t*.prompt.txt`): t1 설계서 있는 신규 개발(설계서와 다른 최신 지시 + 다음 세션 이어받기) · t2 화면 없는 개인정보 마스킹·접근 로그 · t3 오타 하나 · t4 계획만 요청(파일 수정 금지).
- 채점: 독립 레인이 A/B 를 모른 채 X/Y 로 7항목 1~5점(`scores-rep*.md`). 열쇠 = `blind-key-rep*.json`.

## 결과
| 비교 | A | B | 우세 |
|---|---|---|---|
| t1 1회 | 26 | 33 | B — 가장 큰 차이는 A 의 설계서 무단 수정 1건(2회차에선 B 도 같은 수정 → 우연) |
| t1 2회 | 27 | 28 | B 근소 |
| t2 1회 | 24 | 27 | B |
| t2 2회 | 27 | 30 | B |

차이가 난 5건이 모두 B 쪽, 진 경우·회귀 0. 크기는 작다.

## 판정과 한계
합의한 채택 조건(차이 있음 · 회귀 없음)을 충족 → 채택. 한계: 과업당 1~2회 · 채점자 1 · 계획 단계만(구현 품질은 미측정) · Opus 5.5 한 모델 · Claude Code 한 CLI. 두 결과 모두 t1 에서 설계서 원본을 고친 것(앵커 무관 공통 결함)은 이 문안이 막지 못한다.
