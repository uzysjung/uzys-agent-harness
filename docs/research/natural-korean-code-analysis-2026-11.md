## 2. ⓑ SKILL.md 문장 초안

- **B1 — 추가.** L20 끝에 붙인다.
  > 연결어미(‘-고’, ‘-며’, ‘-지만’)와 ‘그리고·그러나’ 같은 접속어 뒤에 습관처럼 쉼표를 찍지 않는다. 끊어 읽지 않으면 뜻이 헷갈릴 때만 쓴다.

  예시 절(L40 앞)에도 한 줄 추가한다.
  > - “설정을 바꾸고, 다시 실행한다.” → “설정을 바꾸고 다시 실행한다.”
- **B2 — 교체.** L27 의 “단순한 취향 차이는 수정 사유로 삼지 않는다.”를 아래로 바꾼다.
  > 고칠 이유를 한 문장으로 댈 수 없으면 고치지 않는다. 취향 차이는 이유가 아니다.
- **B3 — 교체.** L31 의 “새로운 반복과 마크다운 깨짐이 없는지 확인한다.”를 아래로 바꾼다.
