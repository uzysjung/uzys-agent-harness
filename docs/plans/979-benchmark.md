# #979 유사 서비스 실측 — 근거 표

> 이슈 #979 · 2026-11-16 실측 · `docs/plans/979-design-system-plan.md` §4.4 의 근거 파일. 프리셋 표가 이 값을 가운데 값 · 범위로 줄여 쓴다.
> 빌려 오는 것은 **스케일과 구조**뿐이다 — 색 · 로고 · 서체 파일은 옮기지 않았다.

## 0. 어떻게 쟀나

| 항목 | 내용 |
|---|---|
| 브라우저 | 직접 띄운 헤드리스 Chromium(Playwright 1.64.0 + `chromium_headless_shell-1248`, 스크래치패드에 복사). 사용자 Chrome 에 붙지 않았다. 처음 시도한 `npx playwright install chromium`(1.49.1)은 내려받기가 432 KB 에서 멈춰 중단했다 |
| 폭 | **375px** = iPhone 13 에뮬레이션(터치 · 모바일 UA)에 뷰포트 375×812 · **1440px** = 데스크톱 1440×900. 둘 다 `ko-KR` 로캘이라 몇 곳은 한국판으로 넘어갔다(아래 "실제 URL") |
| 읽은 값 | 기획 §4.4 의 스니펫과 같은 속성(`getComputedStyle` + `getBoundingClientRect`)을 닻마다 읽었다. 닻은 자동 탐지(첫 `h1` · 채워진 버튼 중 가장 큰 것 · 버튼 높이 분포 · 같은 줄 버튼 사이 가로 간격 분포 · 왼쪽에 붙은 높은 패널 · 화면 아래에 붙은 고정 막대 · 같은 줄 상품 이미지의 개수 · 간격 · 비율)로 고르고, 열 수와 오탐은 스크린샷으로 대조했다 |
| 예의 | 공개 화면만 · 로그인 · 폼 제출 · 동의 버튼 클릭 없음. 사이트당 페이지 로드 2~6회(폭 2개 × 1~3회) |
| 판정 방법 | 서비스별 값 → 가운데 값(3곳 이상) · 범위(2곳). 자간은 px 을 글자 크기로 나눈 em 으로 적는다 |
| 원본 | 서비스별 JSON 과 스크린샷은 실행 환경의 스크래치패드에 있다(날짜가 바뀌면 지워진다). 이 표가 보존본이다 |

**막힌 곳.** Uniqlo(`uniqlo.com/us/en/women/tops`) — 두 폭 모두 403 "Access Denied" → Allbirds · Nike 로 대체.
Medium(`medium.com/tag/design`) — 375px 은 200, 1440px 은 403 보안 확인 화면 → B2C 표본에서 뺐다.
네이버 웹툰(`comic.naver.com/webtoon`)은 열렸지만 375px 이 다른 사이트(모바일판)로 넘어가 두 폭의 화면이 달라 참고로만 적는다.
Nike 와 Airbnb · 29CM 의 375px 화면에는 쿠키 · 가입 유도 창이 덮여 있었다(누르지 않았다). 값은 그 아래 DOM 에서 읽었다 — 창이 레이아웃을 바꾸지는 않는다.

## 4. 자간 — 관측만 적는다(컨셉 고정값을 만들지 않는다)

표본에 넣은 열 곳(SaaS 3 · B2C 3 · 커머스 4)의 `body` 자간은 두 폭 모두 `normal` 이었다. 0 이 아닌 값은 제목 · 강조 몇 곳뿐이다 — GitLab 화면 제목 −0.01em,
웹툰 문단 −0.04em, Allbirds 가격 +0.05em · 띠 배너 +0.05em, Medium(375px 만 열림) 문단 −0.003em. 부호가 서체와 용도에 따라 갈린다는 기획 §1.5 의 판단과 맞는다.
자간 값은 서체를 정한 뒤 그 서체 공급자 값이나 실측으로 정한다.

## 5. 이 표로 말할 수 없는 것

- **섹션 간격**은 자동 탐지로 잴 닻이 없어 재지 않았다. 프리셋의 섹션 간격은 계속 `[가정]` 이다.
- **B2C 의 읽기 폭**은 세 곳이 서로 다른 구조(전폭 · 앱 셸 · 984px)라 가운데 값을 낼 수 없다.
- **결제 · 장바구니 화면**은 로그인 · 장바구니 담기가 필요해 재지 않았다.
- **SaaS 표본은 개발자 도구 쪽(GitHub · GitLab · Hugging Face)에 치우쳐 있다.** 대시보드 · CRM 형 SaaS 는 로그인 없이 열리는 제품 화면을 찾지 못했다.
- 한 번씩만 쟀다. 사이트가 A/B 실험 중이면 다른 판을 봤을 수 있다.
