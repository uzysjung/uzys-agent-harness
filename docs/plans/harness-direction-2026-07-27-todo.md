## A. 차단 방향 뒤집기 — 가장 급한 것

사용자 체감("뭐만 하면 다 안 된다")의 기계적 실체이자, **비가역 손상 차단이 0건**인 상태다.

- [ ] **A1. `guard-bash.sh` 신설** — 비가역 4종(main 직접 커밋 · `push --force`/`--force-with-lease` ·
      `reset --hard` · 시크릿 커밋)을 PreToolUse `Bash` 매처로 차단. 각각 **음성 대조 통과 기록**을
      남긴다(되돌린 코드가 typecheck 를 통과했는지까지 — 빌드 파손 FAIL 은 증거가 아니다).
- [ ] **A2. 되돌릴 수 있는 차단을 exit 1 경고로 강등** — D4 는 지금 **선언 즉시 자기 위반**이다.
      실측 exit 2 지점 7곳 중 6곳(`mcp-pre-exec` 조회 2 · `protect-files` 설정 파일 3 ·
      `spec-drift-check` 문서 1)이 그 정의상 되돌릴 수 있는 것이다.
- [ ] **A3. 차단 로그(ADR-058 D5)** — 차단 1건당 한 줄(`날짜 · 훅 · 대상 · 사유`).
      리포는 `~/.uzys-agent-harness/hook-blocks.log`, 배포판은 프로젝트 로컬 `.uzys-agent-harness/`.
      **A4·C 의 유일한 증거원이다** — 지금은 7곳이 로그 0줄이라 무엇이 실제로 막는지 아무도 모른다.
- [ ] **A4. `mcp-pre-exec` 의 열거 allowlist 교체** — 실연결 서버 derive 또는 위험 파라미터 패턴으로.
      현재 세션 연결 MCP 8종 중 5종(62.5%)이 차단되고, `context7`(허용) vs `claude_ai_Context7`(차단)이
      같은 제품 두 이름이다.

## B. 앵커 사실 게이트 — 1차 지표의 분자를 만드는 장치

- [ ] **B1. 앵커 사실 추출기 + 게이트(글롭)** — `CLAUDE.md`·`.claude/CLAUDE.md`·`templates/**/*.md`
      에서 백틱 경로 · npm 스크립트명 · 훅 참조 · "N개" 개수 주장을 뽑아 디스크·`package.json`·
      `.github/workflows` 와 대조. **음성 대조 필수**(없는 파일명을 넣어 red 를 눈으로 본 뒤 증거로).
      **선행**: 면제 표식 스윕 — 실측 백틱 경로형 토큰 188개 중 디스크 미해결 21개(11%)이고 상당수가
      의도적 과거 기록·플레이스홀더다. fail-closed 도입 전에 표식을 붙인다.
- [ ] **B2. 미파싱 토큰 수 공시** — 추출기가 파싱 못 한 토큰을 세 번째 값으로 노출.
      *위험이 큰 주장일수록 지표에서 사라지는* 구멍을 막는다(ADR-058 §굿하트).
- [ ] **B3. 루트 앵커를 게이트 범위에 넣기** — 지금 루트 `CLAUDE.md` 를 읽는 테스트는
      `evidence-templates` 하나뿐이고, `resident-doc-asset-reachability`·
      `resident-rule-reference-liveness` 의 `isResidentDoc()` 은 루트를 범위 밖으로 둔다.
      **이번 리뷰가 잡은 거짓 3건이 전부 무게이트였던 이유다.**
- [ ] **B4. 우리 `settings.json` 도 파리티 게이트 입력으로** — `settings-reference-parity` 는
      `templates/settings.json` 만 본다. 그래서 죽은 `hito-counter.sh` 배선이 25릴리즈를 살아남았다.
      `no-false-ship` 이 "`templates/` 만 보면 놓친다"고 경고한 그 실수의 반대 방향판.

## D. 감축 실행 — 워크플로 산출 목표치

- [ ] **D1. 거버넌스 5개 룰 압축 — 조사 완료, 4개는 승인 대기.** deep-research + 5 페르소나 +
      최종 검증 결과(2026-07-27): **5개를 한 파일로 접는 안은 기각**됐다. 근거 셋이 실측이다 —
      ⓐ **파일 = 배포 스코프**(`src/manifest.ts:63-73` COMMON/DEV/UI). 한 파일로 접으면
      project-management·growth-marketing 트랙에 `npm run ci`·branches 88 을 안기거나 문서 규약을
      통째로 잃는다(`tests/installer-11-track.test.ts:48-56`). ⓑ **5개 중 4개가 배포판과 byte-동일**
      이고 그중 2개는 테스트가 동일성을 강제한다(`doc-governance-baseline-rule.test.ts:93` ·
      `evidence-templates.test.ts:197`) → 낯선 설치자의 상주 룰 변경 = **Major CR, 승인 필요**.
      ⓒ 루트 앵커가 이미 시점×판정주체 표를 갖고 있어, 압축본을 또 만들면 `doc-governance` 가
      금지하는 "같은 사실 두 곳"을 새로 만든다.
      → **지금 손댈 수 있는 것은 `ship-checklist` 하나**(배포 사본과 이미 다르고 내용 계약 테스트
      0건). 압축안 = 48 → 38줄 / 5,066 → 2,497 bytes(−51%, **5개 합 기준 −12.5%**, dev 트랙 한정).
      **경고 3건이 열려 있다**: ⓐ 최종 검증이 `needs-revision`(루트 앵커에 거짓 1건을 되돌려 놓고
      그 자리는 무게이트) ⓑ **이 PR 로 D1 을 `[x]` 로 닫으면 남은 262줄을 완료로 오인**한다
      ⓒ 마찰 감소는 과장 — 지운 8건 중 대부분이 "의무"가 아니라 "의무를 가리키는 두 번째 문장"이고
      그 의무를 담은 룰들은 여전히 같이 상주한다.
      **상주 지표는 이 변경을 재지 않는다** — `src/context-cost.ts` 는 `templates/` 만 읽는다.
- [ ] **D2. `paths:` frontmatter 도입** — 룰 33개 중 **0개**가 쓰고 있다. 삭제 없이 상주만 줄이는
      공식 메커니즘(이 리포 −184줄 · 배포판 −299줄 추정).
- [ ] **D3. 배포판 4건** (메인테이너 승인 완료 2026-07-27):
