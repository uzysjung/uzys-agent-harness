# ADR-059: 비가역 git 조작은 호스트 규칙으로 막는다 (로컬 가드 기각)

- Status: Accepted
- Amends: ADR-058 (§비가역 차단 0건 진단의 처방 부분)

## Context

ADR-058 이 실측한 문제는 **방향이 거꾸로**라는 것이었다 — 되돌릴 수 없는 것(강제 푸시 · main
직접 커밋 · 시크릿 커밋)은 아무것도 안 막는데, 되돌릴 수 있는 것(문서 동기화 · MCP 조회 ·
`.env` 편집)은 로컬에서 막고 있었다.

그 처방으로 백로그 A1/A3 은 **로컬 가드**를 설계했다. 1차안은 Claude Code 의 Bash 매처 훅이었고,
적대적 검토가 우회 30여 종(`git -C`·`bash -c`·`git push "--force"`)과 오탐 6종을 잡아내 판정층을
`.git/hooks/pre-commit`·`pre-push` 로 내렸다. 그 이동으로 순 마찰은 7→12 에서 7→9 로 줄었다.

메인테이너가 그 처방 자체에 이의를 제기했다 — *"강제 푸시 main 직접 커밋 막겠다고 계속 훅에서
확인하는 것은 좀 아니지 않나?"* 확인해 보니 **더 나은 층이 비어 있었다**: 리포는 PUBLIC 인데
`main` 에 브랜치 보호가 **없었고**(`Branch not protected`), 룰셋도 **0개**였다.

## Decision

**되돌릴 수 없는 git 조작은 GitHub 저장소 규칙(ruleset)으로 막는다. 그 목적의 로컬 훅은 만들지
않는다.**

- `main` 룰셋 — `deletion` · `non_fast_forward`(강제 푸시) · `pull_request`(리뷰 가능한 ref 경유),
  `bypass_actors: []`.
- 시크릿 스캐닝 + 푸시 보호 활성.
- 배포물에 `templates/scripts/protect-branch.sh` 를 실어 설치자도 같은 규칙을 걸 수 있게 한다.
  설치 타깃은 **CLI 중립**(`.uzys-agent-harness/`) — 저장소 규칙은 4개 CLI 와 사람에게 동시에
  걸리므로 `.claude/` 아래에 둘 성질이 아니다.
- 백로그 **A1/A3(로컬 가드 신설)은 기각**. A2(되돌릴 수 있는 차단의 강등)는 **유효** — 방향의
  나머지 절반이고 서버 규칙이 대신해 주지 않는다.

`required_approving_review_count` 는 **0** 이다. 1인 메인테이너는 자기 PR 을 승인할 수 없어
아무도 만족시킬 수 없는 규칙이 되고, 그런 규칙은 지켜지는 대신 꺼진다. 여기서 얻는 것은 제3자의
서명이 아니라 **변경이 리뷰 가능한 ref 를 거친다**는 사실이다.

## Alternatives

| 대안 | 기각 사유 |
|---|---|
| Bash 매처 훅으로 명령 문자열 검사 | 명령마다 발동하고, 문자열 정제층이 우회 30여 종과 오탐 6종의 **공통 원인**이었다 |
| `.git/hooks/pre-commit`·`pre-push` | 검토가 개선안으로 채택했던 안. 그래도 ⓐ `--no`+`verify` 로 넘어가고 ⓑ 클론마다 재설치해야 하고 ⓒ 로컬 커밋 — **되돌리기 쉬운 지점** — 을 막는다. 비싼 지점은 main 반영이다 |
| 규칙 없이 프로즈 유지 | ADR-058 이 이미 실패로 판정한 상태다 |

## Consequences

- **얻은 것**: 우회 불가(`--no-verify` 무효) · 로컬 비용 0 · 클론마다 설치 불필요 · CLI 중립.
  실측 확인: 빈 커밋으로 일반 푸시와 강제 푸시를 시도해 둘 다 `GH013` 거절, 로컬 원상복구.
- **덮지 못하는 것**(스크립트가 출력하고 룰에도 적었다): `reset --hard` 등 커밋 전 작업 파괴 ·
  인식 가능한 형식이 아닌 시크릿 · 기본 브랜치 외 브랜치.
- **릴리즈 절차 영향 없음** — 직전 릴리즈들이 이미 PR 경유였다(`#260`). 태그 푸시는 브랜치 규칙
  대상이 아니다.
- **긴급 시** 설정에서 룰셋을 끌 수 있다. 되돌리기 쉬운 쪽에 탈출구를 둔 것은 의도다.
- **상주 비용** +44 tok/세션(전 트랙, items 무변경) — 룰이 스크립트의 존재를 가리키는 3줄.
  근거 설명은 스크립트 헤더로 내려 상주에서 뺐다.

## 적용 범위

이 결정은 **기본 브랜치에 대한 비가역 조작**에 한정된다. 로컬 전용 파괴(`reset --hard`), 기본
브랜치 밖 작업, 시크릿 이외의 민감 정보는 범위 밖이고 여전히 프로즈뿐이다.
