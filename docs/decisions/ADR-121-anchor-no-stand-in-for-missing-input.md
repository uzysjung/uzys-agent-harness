# ADR-121: 배포 앵커 §1 에 "필수 입력이 없으면 무엇이 없는지 보고하고, 진짜처럼 보일 대체 결과를 만들지 않는다"를 넣는다

- Status: Accepted
- Date: 2026-11-09
- PR: (머지 때 채움)
- Amends: ADR-091 결정 1(앵커는 사용자 문안) — 사용자가 측정된 후보 문장의 채택을 결정했다(2026-11-09, #513).
- Context: #513 변별 과제 묶음(비공개 과제 · 공개 결과 = `docs/plans/513-probe-suite/` 브랜치 문서)에서, 과제가 기대는 입력 파일이 없을 때
  에이전트가 그 입력을 지어내 결과 파일을 만들고 "완료"로 보고하는 사고를 쟀다.
  - 확인 실행(새 시행 5회 · 한 배치 · GLM-5.3 / GLM-5.3-flash): 하네스 없음 0/10 · **하네스 26.185.0 0/10** — 하네스가 이 사고에 대해 하네스 없음과 같다.
    한 시행은 지어낸 값을 "실제 수치"라고 적었다(선별 실행).
  - 앵커 §1 의 "Make assumptions visible when they affect the result." 뒤에 아래 문장을 넣은 시험 팔: **8/10**(GLM-5.3 5/5 · p≈0.004, flash 3/5).
  - 과잉 멈춤 대조(같은 과제에 입력이 있을 때 · 묻지 말아야 할 명확한 이름 바꾸기): 시험 팔 10/10 · 10/10 통과 — 멈추지 않아야 할 곳에서 멈추지 않았다.
  - 사용자 전역 원칙과 배포 앵커 어디에도 이 상황을 다루는 문장이 없었다(대조군을 넣은 부재 확인).
- Decision:
  - 배포 앵커 `templates/CLAUDE.md` §1 첫 문단 끝에 측정한 문장을 그대로 넣는다.
    ```
    When an input the task depends on is missing, report what is missing and what it blocks
    instead of producing stand-in results that could pass for real ones.
    ```
  - 이 리포는 자기 자신에 하네스를 설치하지 않으므로, 개발 레인 문서 `.claude/CLAUDE.md` 에 같은 결정을 한국어로 둔다(ADR-120 과 같은 배치).
- Alternatives:
  - **넣지 않는다**: 기각. 하네스가 이 사고를 전혀 줄이지 못하고(0/10), 한 문장으로 줄어드는 것이 확인됐다.
  - **경로 룰 · 스킬로 둔다**: 기각. 입력이 없는 상황은 파일 종류와 무관하고, 스킬은 그 상황이 "스킬의 일"로 보이지 않아 열리지 않는다 — 상주 앵커여야 그 순간에 닿는다.
  - **"멈추고 묻는다"로 쓴다**: 기각. 측정한 문장은 보고를 요구할 뿐 멈춤을 요구하지 않는다. 멈춤 문구는 입력이 있는 대조 과제에서 과잉 멈춤을 만들 위험이 있고, 측정되지 않았다.
- Consequences:
  - 4 CLI 설치자가 매 세션 읽는 앵커가 약 +39 토큰 늘어난다(tooling 지시문 ~4,166 → ~4,205).
  - 효과의 근거는 GLM 두 등급뿐이다. 상위 등급(Opus 급)은 미측정 — #513 의 상위 등급 실행에서 같은 항목으로 잰다.
  - 그 상황의 시행에서는 멈추고 설명하느라 출력 토큰이 늘었다(시험 팔/하네스 항목 중앙 GLM-5.3 1.53배 · flash 0.90배).
  - 측정은 문장 하나를 넣은 시험 팔로 했고, 표적 항목을 보고 고른 문장이라 선별 실행이 아닌 새 시행(확인 실행)으로만 효과를 판정했다.
