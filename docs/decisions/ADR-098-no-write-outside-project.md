# ADR-098: 프로젝트 밖은 세 동작 모두 쓰지도 지우지도 않는다 — 링크로 이어진 자리 포함

- Status: Proposed
- Date: 2026-10-04
- PR: (머지 직전 채움)
- Issue: #678 (uninstall 쪽은 #668 · v26.163.0)
- Supersedes: ADR-062 의 "슬롯 밖 파일(`settings.json` · `rules/*.md`)을 공유 dotfiles 로 링크해 두면 **링크를 따라 쓴다**" 한 줄 한정 — 스킬 복원 결정과 스킬 슬롯 술어(`foreign-slot.ts`)는 그대로다
- Context: 설치자가 하네스 폴더(`.claude/` · `.claude/rules/` · `.agents/rules/`)나 그 안 파일을 프로젝트 밖(dotfiles 등)으로
  링크해 두면, install · update 가 링크를 따라가 **프로젝트 밖 파일을 하네스 내용으로 덮었다**(#678 — 26.163.0 재현 2/2: 파일 링크 ·
  폴더 링크). 그 폴더를 공유하는 다른 프로젝트가 함께 바뀐다. 이는 설치자에게 한 약속과 어긋난다 — USAGE "*This project only*
  means *no other project is affected*" · 루트 CLAUDE.md "설치자 파일(기록에 없는 것): 세 동작 모두 건드리지 않는다". 밖의
  실체는 이 프로젝트의 설치 기록에 없다. uninstall 은 v26.163.0(#668)에서 이미 "실체가 밖이면 남김 + 경로" 로 바뀌어, 세
  동작의 규칙이 갈라져 있었다.
- Decision: **install · update(`--reinstall` 포함) · uninstall 모두, 링크를 따라간 실체가 프로젝트 밖이면 그 자리에 쓰지도 지우지도
  않고 백업·기록도 하지 않으며, 화면에 링크 자리와 실체 경로를 한 줄로 말한다.** 판정은 한 함수(`src/outside-project.ts`
  `isOutsideProject` — realpath 기준, 아직 없는 파일·깨진 링크도 실체 위치로)를 세 동작이 같이 쓴다. 프로젝트 **안**을 가리키는
  링크는 지금처럼 따라가 쓴다. `.claude` 폴더 자체가 밖 링크면 그 아래는 전부 건너뛰고 한 줄로 알리며 exit 0 이다(uninstall 이
  같은 상태를 "남김" 으로 다루는 것과 같은 규칙). 사용자 결정 2026-10-04: "현재 프로젝트 안에만 스킬 · 룰 · 훅을 생성하도록 설계했으니
  install · update 도 그렇게 따라야 한다."
- Alternatives:
  - 쓰기는 링크를 따라가되 화면에 "밖에 썼다(공유됨)" 를 알리고, 지우기만 막는다(ADR-062 유지) — 쓰기는 파일 단위 백업으로
    되돌릴 수 있다는 근거였으나, 기준은 되돌릴 수 있는가가 아니라 **다른 프로젝트가 영향을 받는가**다. 기각.
  - 파일 링크만 막고 폴더 링크는 따라간다 — 경우별 예외라 한 원칙에 어긋나고, 폴더 링크가 공유 피해가 더 크다. 기각.
- Consequences:
  - `.claude/` 나 룰 폴더를 dotfiles 로 공유하던 설치자는 install · update 로 하네스 파일을 **받지 않는다** — 화면이 링크 자리와 경로를
    말한다. 공유 자리를 갱신하려면 설치자가 직접 옮긴다. (ADR-062 가 지원 구성으로 적었던 사용 방식의 계약 변경.)
  - 함께 쓰는 파일(`settings.json` 등)이 밖 링크면 하네스 몫도 얹지 않는다 — 훅이 배선되지 않았다는 사실이 같은 줄로 나온다.
  - 외부 스킬(`npx skills add`)도 같은 판정이다: 스킬 자리(`.claude/skills` · `.agents/skills`)가 밖으로 풀리는 CLI 는 그 자리로
    도구를 부르지 않고(남은 CLI 가 없으면 부르지 않는다) 화면이 자리와 경로를 말하며, 밖 자리의 파일은 설치 기록에 적지 않는다.
  - 아직 덮지 않은 쓰기 자리(관측되면 같은 함수로 넓힌다): CI 스캐폴드 · `.env.example`(없을 때만 만든다) · 빈 폴더 mkdir ·
    `refreshNeutralHelpers`(원래 모든 링크를 건너뛴다) · `.uzys-agent-harness/` 폴더 자체가 밖 링크일 때의 **설치 기록 파일**
    (헬퍼 스크립트는 안 쓰지만 기록은 링크 너머에 쓴다 — 기록 없이는 update · uninstall 이 설 자리가 없어 남겼다. 같은 밖 폴더를
    두 프로젝트가 공유하면 기록이 서로를 덮는다).
  - `.claude.backup-*` 폴더 백업의 "최상위 링크는 실체를 복사" 규칙(`fs-ops.ts` copyBackupDir)은 백업의 의미만 정하며 그대로다.
