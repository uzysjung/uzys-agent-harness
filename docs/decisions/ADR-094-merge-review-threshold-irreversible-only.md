# ADR-094: 이 리포의 머지 전 독립 리뷰 문턱 = 설치자 디스크·공유 상태를 되돌리기 어렵게 바꾸는 변경 · 릴리즈 배선

- Status: Accepted
- Date: 2026-09-21
- PR: #511
- Amends: ADR-087 Decision 4 (이 리포의 문턱 "설치자에게 나가는 것 = `templates/` · `src/` · 설치기 동작" → 되돌리기 어려운 변경으로 좁힘). Decision 1~3 은 그대로.
- Context: ADR-087 이 이 리포의 문턱을 **경로**(`templates/` · `src/`)로 적었다. 경로는 판정이 쉽지만 위험과
  어긋난다 — 이슈 #454 의 실측 두 건(2026-09-20): PR #478(#476, 설치 헤더 숫자 하나)에 독립 리뷰
  worktree 약 6분 · 45 tool calls 가 돌았는데 틀려도 설치자가 잃는 것이 없고 변이 대조가 이미 물고
  있었다. PR #479(#477, update 가 설치자 디스크 파일을 지움)는 "되돌리기 어려운 것"에 실제로 해당했고
  리뷰가 값을 했다. 같은 `src/` 인데 한쪽은 과했고 한쪽은 필요했다 — 경로가 아니라 **결과의 되돌리기
  비용**이 갈랐다. 사용자가 이슈에 후보 문장을 썼다: *"설치자 디스크·공유 상태를 되돌리기 어렵게
  바꾸는 변경 · 릴리즈 배선"*.
  같은 감사에서 배포 행의 "리뷰 필수"가 실무와 어긋난 것도 드러났다 — 릴리즈 PR(#506 · #510)은 CI 만으로
  머지됐고 사용자가 승인했다. 룰이 요구하는 것과 실제로 하는 것이 다르면 다음 사람이 룰을 우회로 배운다.
- Decision:
  1. 이 리포의 머지 전 독립 리뷰 문턱 = **설치자 디스크·공유 상태를 되돌리기 어렵게 바꾸는 변경**(update ·
     uninstall 의 삭제·덮어쓰기 경로 · 백업 규약 · 심링크 처리 · 저장소 설정) · **릴리즈 배선**. `src/` ·
     `templates/` 라는 경로 자체는 문턱이 아니다. 갈리면 독립 리뷰 쪽으로(ADR-087 유지).
  2. 배포 행의 "리뷰 필수" 의 뜻 = **이 릴리즈에 든 문턱 위 변경이 머지 전 독립 리뷰를 받았는지 확인**한다.
     릴리즈 커밋(bump · CHANGELOG) 자체에는 새 리뷰를 걸지 않고 릴리즈 CI(`ci` · `docker-e2e` `needs:`)가
     판정한다. 배포판 Delivery 룰의 "배포 전 독립 검증" 문장은 설치자 프로젝트 일반론이라 그대로 둔다.
  3. 상시 스위트의 잣대를 룰에 적지 않는다 — **설치자에게 안착하나 · 일어나면 안 되는 일을 막나**, 그 밖은
     값을 바꾸는 PR 의 검증으로. 판정 표는 `docs/plans/test-suite-audit-2026-09-21.md`(이 결정의 근거 문서).
- Alternatives:
  - 경로 문턱 유지 + 예외 목록 — 기각. 예외 목록이 두 번째 사본이 되고, #478 류가 나올 때마다 늘어난다.
  - 문턱을 게이트(변경 파일 글롭)로 — 기각. "되돌리기 어려운가"는 판단이다(ADR-087 Alternatives 와 같은 사유).
  - 배포 행에 실제 리뷰 레인을 추가 — 기각. 릴리즈 커밋은 bump·CHANGELOG 뿐이고 그 정합성은 `docs-supply-chain`
    게이트가 문다. 사람이 안 도는 절차를 룰에 두면 우회가 관행이 된다(#237 전례).
- Consequences:
  - `src/` 변경이라도 되돌리기 어려운 결과가 없으면 CI 만으로 머지된다 — 문구·숫자·렌더·카탈로그 설명 변경.
    그 위험은 릴리즈 게이트(docker-e2e 3종 · install-matrix)가 받는다.
  - 되돌리기 어려운 변경의 리뷰는 유지된다 — #479 형태는 계속 리뷰를 받는다.
  - `.claude/rules/test-policy.md` §시점별 검증 두 문장과 `.claude/rules/ship-checklist.md` Review 항목이 이
    결정을 따른다. 배포판(`templates/rules/`)은 변경 없음.
  - 측정은 없다 — 효과는 다음 사이클에서 "리뷰 레인이 돈 PR 수 / 리뷰가 블로커를 낸 PR 수"로 본다.
