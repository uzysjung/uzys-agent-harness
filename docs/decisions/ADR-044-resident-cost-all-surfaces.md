# ADR-044: 상주 비용 = 설치가 상시 컨텍스트에 올리는 전부 (룰 포함)

- Status: Accepted
- Date: 2026-07-19
- PR: #231 (v26.117.0)
- Supersedes: ADR-043 의 `Context Cost per Install` **범위 정의**(스킬 한정). 지표 자체와 짝 구조
  (양 + 사후 품질)는 그대로 유효 — 범위만 정정한다.
- Context:
  ADR-043 은 1차 NSM 을 `Context Cost per Install`(양) + `Justified Asset Ratio`(품질)로 세우면서
  전자를 **"상주(skill descriptor) + 발화(SKILL.md body)"** 로 정의했다. v26.116.0 에서 발화
  계측을 붙이며 룰 토큰(~6,705, 템플릿 전체)이 계측 밖이라는 것이 드러나 "열린 결정"으로 남겼고,
  사용자가 결정을 위임했다("A부터 정해").

  착수 후 실측 (tooling 트랙, 실제 설치 계획 기준):

  | 상주 표면 | 토큰 | 비중 |
  |---|---|---|
  | rules | ~3,094 | **60%** |
  | CLAUDE.md 스캐폴드 | ~938 | 18% |
  | agent descriptors | ~615 | 12% |
  | **skill descriptors** | **~547** | **10%** |
  | 합계 | **~5,194** | |

  즉 기존 정의는 상주 비용의 **10% 만** 재고 있었고, 그 값이 위저드·설치 헤더에
  `session-start context cost: ~N tokens` 로 **사용자에게 그대로 표시**되고 있었다. 실제의
  9분의 1을 전부인 양 보여주는 것은 계측이 아니라 오보다 (no-false-ship).
- Decision:
  1. **`Context Cost per Install` 의 상주 항을 "설치가 상시 컨텍스트에 올리는 전부"로 정정한다.**
     판정 기준은 **표면 열거가 아니라 "상주인가 발화인가"** — 새 표면이 생겨도 기준이 그대로다
     (문서 게이트를 글롭으로 바꾼 것과 같은 취지, no-false-ship "게이트는 열거하지 말고 훑어라").

     | 표면 | 상주 | 발화 |
     |---|---|---|
     | rules | 전문 | — |
     | CLAUDE.md 스캐폴드 | 전문 | — |
     | skills | descriptor | body |
     | agents | descriptor | 프롬프트 본문 |
     | hooks | — | — (실행될 뿐 컨텍스트 미탑재) |

  2. **계측은 설치 계획(manifest)에서 한다** — `residentCost(entries)`. `applies` 로 걸러진
     엔트리를 받으므로 트랙별 실제 설치분이 반영된다. `templates/` 전체 합계 같은 부풀린 수치를
     쓰지 않는다.
  3. **표시도 함께 고친다** — `formatResidentCostLine` 이 총합 + 내역(rules/CLAUDE.md/skills/
     agents)을 보여준다. 총합만 보이면 어디가 비싼지 알 수 없고, 60%를 차지하는 룰이 계속
     안 보인다.
  4. 미계측 항목은 그대로 명시한다: 외부 자산(설치 시점에 콘텐츠 미상) · MCP tool schema(서버
     제공) · hooks(비용 대상 아님).
- Alternatives:
  - **스킬 한정 유지(룰 제외)** — 기각. 결정적 사유는 수치가 아니라 **굿하트 구멍**이다:
    SKILL.md 산문을 룰 파일로 옮기면 *발화 시에만 내던 비용이 매 세션 상주로 바뀌어 사용자에겐
    악화*인데 지표는 개선으로 표시된다. **사용자를 나쁘게 만드는 리팩터링을 보상하는 지표는
    없느니만 못하다.** ADR-043 이 짝 구조로 굿하트를 막으려 했는데 정작 더 큰 구멍이 열려 있었다.
    계약 테스트("스킬 body → 룰 이동 시 상주 증가")로 이 구멍을 봉한다.
  - **룰만 추가하고 CLAUDE.md·agents 는 유지 제외** — 기각. 같은 기준으로 훑으면 셋 다 상주다.
    하나만 넣으면 다음 drift 서식지가 나머지 둘이 된다 (표면 열거식 대응의 실패 패턴).
  - **상주 + 발화를 하나의 "총 비용"으로 합산** — 기각(ADR-043 판단 유지). 상주는 전원이 매 세션,
    발화는 트리거 시에만 무는 비용이라 단위가 다르다. 합치려면 "평균 트리거율" 같은 근거 없는
    상수가 필요하다 (heuristic threshold 금지).
- Consequences:
  - 공표 수치가 커진다: tooling 트랙 상주 ~547 → **~5,194**. 이는 악화가 아니라 **그동안 안 보이던
    비용이 드러난 것**이다. ratchet baseline 은 새 정의 기준으로 다시 잡는다.
  - **룰이 최대 비용 항목(60%)** 이라는 사실이 처음 드러났다 — 후속 검토 대상 1순위가 스킬이
    아니라 룰이 될 수 있다. 단 룰은 "모델이 스스로 하지 않는 판단"을 담는 축이라 단순 축소가
    답이라고 단정하지 않는다. 판정은 ADR-043 의 2단계(eval)를 따른다.
  - `Justified Asset Ratio` 는 **여전히 미구현** — 이 ADR 로 바뀌지 않는다.
