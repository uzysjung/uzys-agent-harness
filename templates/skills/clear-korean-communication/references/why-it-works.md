# 왜 통하나 (근거, 선택적)

Light support if you want to defend the format — not part of the body. Reason with
each, don't just cite it.

- **Lead with the recommendation**: BLUF (Bottom Line Up Front) — readers decide off
  the conclusion, so the ask goes first even though it's item 2 in the four-part rule.
- **Keep supporting reasons few (~3), one scannable table**: executive-decision-slide
  and working-memory (~7±2) guidance — more dilutes and pushes the reader back into
  analysis-mode. The same limit is why a referent collision has to be *drawn* rather
  than narrated: prose makes the reader hold both objects in working memory while you
  keep talking.
- **Quantify the gap, list all consequences**: As-Is/To-Be gap analysis + ADR
  (Nygard) — an unquantified or one-sided gap isn't a basis for deciding. ADR's
  Consequences section is explicitly two-sided for the same reason.
- **Pre-answer the objection inline**: Amazon Working Backwards PR/FAQ — collapses
  the back-and-forth into one round. "왜 B가 아닌가" belongs in the first message,
  not the second.
- **Contested call? score on explicit criteria**: RICE (Intercom) — a small scoring
  table is more defensible than prose advocacy, and it makes the override visible
  when judgment beats the score.

None of these outrank Step 1. A perfectly BLUF-formatted message about an ambiguous
referent still fails — that is the observed case this skill was built from.
