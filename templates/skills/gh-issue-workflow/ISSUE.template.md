# 변형 A — Task (문제 제기 · 실행 단위)

**육하원칙이 어느 칸에 들어가는가** — 칸 이름을 외우지 말고 이 대응만 본다:

| | 들어가는 칸 |
|---|---|
| **왜**(Why) · **누가**(Who) | `## 배경` |
| **무엇이**(What) · **언제·어디서**(When/Where) | `## 문제` |
| (증명) | `## 근거` |
| (출처) | `## 레퍼런스` |
| **어떻게**(How) | `## 제안` |

---

## 배경 — 왜 · 누가

[왜 지금 이걸 다루는가. **누가** 겪는가(설치받는 사용자 / 운영자 / 리뷰어 / 다음 유지보수자).
 안 고치면 무엇이 계속 일어나는가. 2-4 문장.]

## 문제 — 무엇이 · 언제·어디서

[**관측된 것만** 적는다. 원인 추정은 `## 제안` 으로 내린다 — 둘을 섞으면 추정이 사실로 굳는다.]

- **관측**: [어떤 명령 / 화면 / 버전에서 무엇이 일어났나]
- **기대**: [대신 무엇이 일어나야 하나]
- **범위**: [항상인가, 특정 조건에서만인가. 안 나는 조건을 알면 그것도 적는다]

## 근거

[남이 붙여넣어 재현할 수 있는 형태로. "확인했다"는 근거가 아니다.]

```bash
<재현 명령>
# 실제 출력 (잘라내지 말고, 실패 메시지는 stderr 까지)
```

- 실측 날짜 / 환경: [OS · 버전 — 재현이 환경에 걸리면 이 줄이 판정을 가른다]
- **대조군**: [되는 줄 아는 경우도 같은 절차로 돌렸는가. 그게 함께 실패하면 위 결과는 무효다]

## 레퍼런스

[**링크는 죽는다** — 커밋 메시지 안 링크의 34~43% 가 접근 불가라는 측정이 있다.
 그래서 밖의 자료는 URL 만 두지 말고 **핵심 문장을 인용해 둔다.**]

- 저장소 안: `#N` · `path/to/file.ts:123`   ← 이슈·PR 은 반드시 `#N` 으로. 교차참조 **이벤트**가 남는다
- 저장소 밖: [제목](URL) — > "인용할 한 문장"
- 선행 결정: `#M` 의 `## 방향성` / ADR

## 제안 — 어떻게

[고치는 방향. **강제가 아니라 출발점**이다 — 구현 레인이 더 나은 길을 찾으면 그쪽이 이긴다.]

- [1안: <무엇을 · 어디를>]
- **안 하기로 생각한 것**: [<대안> — 왜 아닌지 한 줄] ← 이걸 적어야 다음에 다시 논의되지 않는다

## 전제 (Given)

[시작 전에 충족돼야 하는 조건. 미충족이면 착수 차단. 없으면 이 절을 지운다.]

- [ ] [예: #N 완료]

## 방향성 (OPEN | YYYY-MM-DD 확정)

[`OPEN` = 사용자 결정 대기 → 착수 금지. 확정이면 **날짜와 채택 근거**를 남긴다.
 옵션이 나열만 돼 있는 것은 결정이 아니라 결정이 없다는 뜻이다.]

- **채택**: [고른 것 + 왜 다른 것을 안 골랐는지]

## 적용 대상 / Acceptance Criteria (When → Then)

대상: `[path/to/file.ts]` 의 `[symbol]` · `[path/to/other]`

- [ ] [When <조건> → Then <관측 가능한 결과>]
- [ ] [경계 하나 — 예외·edge 경로]
- [ ] [위를 고정하는 회귀 테스트가 변경 없이는 red]

## 후속 작업 (Next)

- [ ] [#M 으로 분리한 것 — 이번 범위에서 뺀 것과 그 이유]

# 변형 B — Epic (부모 이슈 / 묶음)

## 배경

[이 묶음이 왜 필요한가. 무엇이 지금 안 되는가. 2-4 문장.]

## 방향성 (OPEN | YYYY-MM-DD 확정)

[하위 전체가 공유하는 결정. 하위마다 다시 정할 필요가 없어야 에픽이 값을 한다.]

- **채택**: [방침 + 근거]
- **하지 않기로 한 것**: [빼기로 한 것 + 왜]

## 하위 작업과 순서

[부모-자식은 gh 로 붙인다(진척은 GitHub 이 표시). 여기에는 **순서와 그 이유**를 적는다.]

1. #N — [무엇] · 먼저 하는 이유: [의존/위험]
2. #M — [무엇] · #N 의 결과가 있어야 판정 가능
3. #L — [무엇] · 독립. 언제든

## 완료 판정 (에픽이 닫히는 조건)

[하위가 다 닫혔다는 사실만으로 닫지 않는다. 묶음 수준에서 관측되는 것을 적는다.]

- [ ] [When <사용자 표면 조건> → Then <관측 결과>]

## 범위 밖 (Non-Goals)

- [이 에픽에서 다루지 않는 것 — 나중에 "왜 저건 안 했지"를 막는다]
