# No False Ship (거짓출하 금지)

검증하지 않은 경로를 "작동한다"고 보고하는 것 = 거짓출하. 틀린 코드는 다음 사람이 고치지만,
틀린 보고는 고칠 게 있다는 걸 아무도 모른다.

**검증한 경로만 주장한다. 검증 못 한 경로는 "미검증"이라고 그대로 쓴다.**
"되어야 한다" / "될 것이다" 는 완료 보고에서 금지 — 추론·기대는 증거가 아니다.

## Surface Parity 의무 (기능 추가·변경 시)

사용자가 그 기능에 도달하는 경로를 **전부 열거**하고 각각 실행 증거를 확보한다. 흔한 표면:

- 대화형 UI / 위저드 — 실제로 렌더되어 선택 가능한가
- 비대화형 CLI 플래그 · API
- 문서 표기 — README / 사용법 / CHANGELOG 의 광고 문구 = 실동작
- 대상 플랫폼별 (OS · 런타임 · 통합 대상 CLI 등 해당하는 것)

**증거 = 실제 실행 산출물만**: 테스트 PASS 출력, exit 0, `--help` 출력, 렌더된 화면.
**한 경로의 증거를 다른 경로에 전용하지 않는다** (플래그가 통과했다고 위저드도 된다고 쓰는 것).

실패한 명령은 산출물을 내지 않는다 — **빈 결과는 부재의 증거가 아니다**. 확인 명령에 `2>/dev/null`
을 붙이면 실패와 "이상 없음"이 구분되지 않는다 (설치돼 있으면 `cli-development.md` 참조).

## 완료 보고 양식

```
| 경로       | 증거                        | 상태   |
|-----------|-----------------------------|--------|
| 위저드     | parity 테스트 PASS          | ✓      |
| CLI 플래그 | 시나리오 exit 0             | ✓      |
| 문서       | grep 광고문구 ↔ 실명령 일치 | ✓      |
| (해당 항목)| —                           | 미검증 |
```

미검증 행이 있으면 보고에 그대로 노출한다. 숨기고 "완료" 선언 금지.

## Drift 구조 차단

같은 목록(카테고리 · 자산 · 플래그)이 2곳 이상에 하드코딩되면 **derive 로 단일화**하거나
**exhaustiveness 테스트 / init-throw 가드**를 추가하기 전에는 머지하지 않는다.
주석 경고는 차단 수단이 아니다.

### 게이트는 열거하지 말고 훑어라

표면을 하나 놓칠 때마다 **그 표면 전용 게이트를 하나 추가**하는 방식은 수렴하지 않는다 —
게이트가 커버하는 목록 자체가 또 하나의 하드코딩 사본이 되고, 목록에 없는 표면이 다음 서식지가
된다. 문서 사실 게이트는 **파일 열거가 아니라 글롭**으로 작성한다. 새 파일이 생겨도 게이트를 고칠
필요가 없어야 하고, 커버 목록을 사람이 기억해야 하면 그 게이트는 이미 실패한 것이다.
과거 기록은 경로 제외나 명시적 표식으로 면제하되 **면제는 표식이 있는 쪽**이어야 한다(기본값 = 검사).

## "미검증"에도 근거가 필요하다

`미검증` 은 면죄부가 아니라 **주장**이다. 왜 못 했는지 + 무엇이 풀리면 되는지를 한 줄로 못 쓰면
그건 미검증이 아니라 **미시도**다. 대개 "불가능"이 아니라 "지금 쓰는 도구로는 안 된다"로 좁혀지고,
그 차이가 곧 우회다. "환경 제약상 불가" 같은 **주어 없는 불가 선언** 금지.

## 초록불이 무는지부터 확인한다 (음성 대조)

**한 번도 실패해본 적 없는 검증은 증거가 아니다** — "동작한다"와 "이 검증이 아무것도 안 본다"를
구분하지 못한다. 새 게이트·테스트는 고칠 대상을 되돌려 **실패하는 것까지 보고** 증거로 쓴다.
대조 자체도 확인한다: 되돌린 코드가 빌드를 통과했는가. 빌드가 깨져서 난 실패는 게이트가 문 게 아니다.

## 위반 발견 시

1. 즉시 정정 보고 — 어느 보고가 어떻게 거짓이었는지 명시한다. 조용히 고치지 않는다.
2. 수정을 최우선으로 처리한다.
3. 재발이면 기록 → 룰 → 구조 게이트 사다리를 탄다 (`recurrence-prevention` 스킬이 없으면 직접).
